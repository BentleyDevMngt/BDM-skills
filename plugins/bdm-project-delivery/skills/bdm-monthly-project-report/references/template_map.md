# Template map — BDM Monthly Project Report master

Master: Form 260 Monthly Project Report, highest revision from
`Standard - Documents\BDM TEMPLATES\Working Copy\200 Project Management - Pre-Contract\`.
Verified against R1. Never carried in this skill.
Built from the pilot project's Monthly Project Report No. 01 DRAFT v0.4 (7 August 2026), the
settled form. All project content stripped; every field bracketed.

## Word structure

Two sections.

| Section | Margins (mm) | Carries |
|---|---|---|
| 0 | 0 / 0 / 0 / 0 | Full-bleed cover banner |
| 1 | L22 R22 T28 B20 | Body and annexures |

Header (section 1): `Monthly Project Report No. [NN] · [Project Name]`
Footer (section 1): `[Project Name] · [Project No.] · MR-[NN] · [D Month YYYY] · DRAFT — NOT FOR ISSUE` + page number

**Both carry project identity.** When rolling forward from a previous report, update the
header and footer — the body can be clean while these still name the last project.

## Tables

| # | Location | Columns | Rows |
|---|---|---|---|
| 1 | Cover banner | 1 | 5 — discipline line, project, address, then the document/date/prepared/reference grid |
| 2 | 1.0 Report particulars | Item · Detail | 4 fixed — Project, Period, Stage, Approvals |
| 3 | 2.0 Status summary | **Section** · Position · Status | 5 fixed — one per body section 3.0–7.0, in order |
| 4 | 3.0 Programme | Key milestone · Programmed finish · Float · Position at [cut-off] | variable |
| 5 | 4.1 Development budget | Development cost · Approved budget · Variations · Forecast cost · Cost to date · Cost to complete | 6 fixed categories |
| 6 | 4.2 Professional fees | Category · Forecast fee · Cost to date · Cost to complete · Status | 6 fixed categories |
| 7 | 4.3 Cost movement | Element · Amount ex GST · Position | variable |
| 8 | 5.0 Approvals | Approval · Reference · Status at [cut-off] | variable |
| 9 | 6.0 Design | Discipline / item · Status at [cut-off] | variable |
| 10 | 7.0 Construction | Pre-construction item · Position at [cut-off] | variable |
| 11 | Annexure A | # · Risk · Position and mitigation · Rating | HIGH only |
| 12 | Annexure B | # · Action · Responsibility · Due | variable |

**Fixed** means the rows do not change between projects. Tables 3, 5 and 6 are fixed;
the rest scale with the project.

## Placeholders

All bracketed: `[Project Name]`, `[Street Address, Suburb QLD Postcode]`, `[NN]`,
`[D Month YYYY]`, `[Principal]`, `[Project No.]`, `[Period start]`, `[period end]`,
`[data cut-off]`, `[LOW / MEDIUM / HIGH]`, `[$]`, `[$ ex GST]`.

Search the finished document for `[` before delivering — no bracket may survive into a
draft that goes to the Director.

## Typography

Body Calibri. Labels on the cover grid are **bold** in BDM bronze `9D7B5B`; values are
plain. Risk ratings: LOW `1A4A2A` · MEDIUM `9D7B5B` · HIGH `B91C1C`, bold.

## Page discipline

Cover 1 page · body 3 pages · annexures 2 pages · six total. The master renders longer
because placeholder rows are verbose; real content condenses. Three pages of body is a
constraint — condense to meet it rather than letting it run.
