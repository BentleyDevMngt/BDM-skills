# bdm-floor-area-schedule (R4 · 2026-10)

Measures a floor area schedule off architectural drawings — from the PDF's own
vector linework — and produces the BDM **Form 405** workbook plus the **405a** A3
markup set, which is also a live Datum file.

## What you get

| Output | Detail |
|---|---|
| **Form 405 workbook** | Nine tabs — Summary · Level Schedule · Area by Category · Apartment Schedule · NSA & Revenue · Unit Mix · Site & Parking · Basis of Measurement · Verification |
| **405a A3 markup PDF** | Cover reconciling to the workbook, then one sheet per level: the architect's vector plan in the BDM frame with every measured polygon as an editable Datum area shape. Datum works the quantities (Workbook button). Baked, so the markups show in Acrobat, Bluebeam and browsers too |
| **Take-off config** | One JSON holding every measured shape — every figure is derived from it, so the outputs cannot disagree |

Held for Director sign-off. Feasibility grade, target ±2%.

**Correcting it:** open the 405a in Datum, drag a corner, Save — then ask for the
schedule to be rebuilt. `read_405a.py` reads the correction back out of the file.

## Templates it uses

`…\BDM TEMPLATES\Working Copy\400 Quantity Surveying\`

- `405-Floor_Area_Schedule_R*.xlsx` — the workbook
- `405a-Area_Markup_Cover_R*.pdf` — the markup cover (generated by `layout_405a.py`)

Always pull the highest revision; ignore `_Superseded`.

## The one thing to take away

There is **no Australian Standard** for measuring building area. GFA (FECA + UCA)
comes from the AIQS *Australian Cost Management Manual*; **GBA comes from the
Property Council / API / REIA *Glossary of Property Terms***, not from the PCA
*Method of Measurement for Lettable Area*.

## Dependencies

Python: `pymupdf`, `shapely`, `numpy`, `pypdf`, `openpyxl`; for the raster
fallback `opencv-python-headless`, `scipy`, `scikit-image`. An embeddable sans font
(Carlito, Liberation or DejaVu). The **bdm-standards** plugin (its `datum-markup`
library — declared as a dependency, so it installs automatically). To bake: Node 18+
with `npm install playwright` and Chromium, Chrome or Edge, plus internet (or a
local copy of the Datum app).
