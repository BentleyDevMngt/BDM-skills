# Source-to-section map — intake checklist

The report creates no new information. Work this checklist before writing anything.
Tick each source as read, or record it as unavailable — an unavailable source is a
finding for Annexure B, not a silent gap.

## 1.0 Report particulars
| Field | Source |
|---|---|
| Project, address | Job folder, BDM appointment |
| Period, data cut-off | Set at intake — period ends month end, cut-off is when gathering stopped |
| Stage | Current position — design development, pre-approval, pre-contract, construction, defects |
| Approvals | Decision notices and referral agency responses in `03_Applications & Approvals\` |

Everything the cover already carries — principal, reference, preparer — stays off this
table. Four rows, not ten.

## 2.0 Status summary
Synthesised from 3.0–7.0. Not sourced independently. One row per body section, in section
order, carrying the section number. No row may exist here that is not a section below.

## 3.0 Programme
| Input | Where |
|---|---|
| Current programme file and revision | `09_Programmes\` — read the native file, not a PDF of it |
| Status date; whether activity has been statused | The programme itself. If absent, float is as-planned — say so |
| Milestones, dates, float | The programme |
| Delay events, NODs, EOTs | `13_Contract\05a_Extensions of Time\`, `…\00_Notice of Delay`, the EOT register |
| Critical path | The programme's own logic, stated as a chain |

Report the programme's currency. If it is superseded, say so and recommend the reissue
with what the next revision must carry.

## 4.0 Cost — BDM Form 425 development-summary basis
| Input | Where |
|---|---|
| Development budget, cost plan, feasibility | `10_Cost Plans\`, `10a_Feasibility\`. If absent → `n/e` throughout |
| Consultant fee register | `02_Project Control\Fee Registers\` — note the version and date |
| Monthly cost report | `05_Consultants\04_Monthly Cost Report\` |
| Contractor's claims | `13_Contract\02/04_Progress Claims\` |
| Progress certificates | Same — certified vs claimed, retention, cost to complete |
| Variations, CSAs | `13_Contract\03_Variations\` + the variation register |

4.1 categories are fixed: Land · Professional fees · Authority fees and charges ·
Construction · Contingency · TOTAL.
4.2 categories are fixed: Executed agreements · Accepted, agreement pending · Issued,
unexecuted · Proposal only, not engaged · Not quantified · TOTAL.

Check the 4.2 categories sum to the TOTAL, and that the TOTAL ties to the named fee
register. State the register version in the Status column.

## 5.0 Approvals
| Input | Where |
|---|---|
| DA / MCU, referral agency | `03_Applications & Approvals\`, decision notices |
| Building approval | Certifier correspondence and job number |
| Utility and authority approvals | `04_Statutory Authorities\` |

Merge related approvals into one row where they move together — a referral agency
belongs with its DA, and minor utility approvals can share a row.

## 6.0 Design
| Input | Where |
|---|---|
| Design meeting minutes | `07_Meeting Minutes\` |
| Drawing revisions | `06_Drawings & Specifications\` |
| Consultant correspondence | `05_Consultants\`, `00_Email Communication\` |
| Conflicts between documents | Anywhere — report the conflict, name both sources, resolve neither |

## 7.0 Construction and delivery
| Input | Where |
|---|---|
| Site / construction meeting minutes | `07_Meeting Minutes\` |
| Claims, certificates, variations, EOTs, notices | `13_Contract\` |
| Site inspections | OneNote inspection notebook |
| Pre-construction items | Tests, surveys, permits, hazardous materials |

Where there is no construction, the section stays and states that — and confirms there
are accordingly no claims, variations, EOTs, notices or defects.

## Sales
| Input | Where |
|---|---|
| Sales meeting minutes | `11_Sales & Marketing\`, `07_Meeting Minutes\` |
| Presales, settlements, revenue movement | Same |

The master has no sales section. Where a project has a sales programme, add **8.0 Sales
and marketing** ahead of the annexures and raise it so the master can be updated. Where
there is none, add nothing.

## Annexures
| Annexure | Source |
|---|---|
| A — Critical risk register | All sections. HIGH only, priority order. MEDIUM in trailing prose |
| B — Outstanding actions | All sections, plus every source that could not be obtained |

## Correspondence — every section
Read every `.msg` in `00_Email Communication` for the period. Do not sample. Search
Outlook mail and calendar for what has not been filed yet. Emails catch movements that
have not reached a formal document; they do not override the job folder.

## Unavailable sources
Any source on this list that does not exist becomes a row in Annexure B — an action to
obtain it, with a responsibility and a due date. That is how the report reports absence.
